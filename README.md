# 🔥 VirangarVPN Bot

Telegram management bot for VirangarVPN.

## Features

- 👥 User management
- 📊 User statistics
- 📢 Broadcast messaging
- 👑 Admin panel
- 🗄 SQLite database
- 🔐 Environment variables
- 📝 Activity logging

## Installation

```bash
git clone YOUR_REPOSITORY_URL
cd VirangarVPN-Bot

python3 -m venv venv
